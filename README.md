# oidc-spa landing page

https://www.oidc-spa.dev

It's built with [TanStack Start](https://tanstack.com/start), [Vite](https://vite.dev), [React](https://react.dev), [Tailwind CSS](https://tailwindcss.com) and [shadcn/ui](https://ui.shadcn.com) (Base UI).

```bash
git clone https://github.com/keycloakify/www.oidc-spa.dev
cd www.oidc-spa.dev
pnpm install
pnpm dev
```
